# REV.IA — DECIFRA.IA

Jogo de plataforma 2D em C11 + Raylib sobre alfabetização algorítmica.

Documentação completa (controles, campanha, compilação no Windows/MSYS2, Linux e macOS, estrutura do código,
testes e limitações): **[docs/README.md](docs/README.md)**.

```bash
make          # compila (precisa da Raylib instalada)
make run      # compila e joga
make test     # testes de lógica (sem Raylib)
```
